# 办公室跟进人规则（V0.2.11）

看板的owner只表示办公室跟进人，不能选择业务员、客户、安装人员或其他名单外发言人。原消息发言人另列，保留需求和沟通来源。

默认名单为李睿琪、张英、银小芹、王星、郭逸、张利伟。仅有外部需求或催问，没有办公室承接依据时待分派；明确交给办公室人员的任务优先，其次根据办公室人员主动承接、协调或持续推动的消息推定。收到、安排、单独转发资料不作为足够的跟进依据。

微信昵称只采用精确确认的对应关系。不能看到字符串包含“张英”就认定此人是张英；“我”必须先核对采集账号身份，“小银”必须先确认其真实身份。来源原昵称、时间、原文始终保留，页面负责人统一显示规范姓名。

已授权人员可从下拉框选择办公室人员，确认或修改负责人。普通同值保存不自动确认；改人不重置优先计时。人工完成、密码、权限和原消息不随规则修正覆盖。

办公室人员或昵称变化时，由管理员授权本机Codex维护private/office_staff.json，结构为names字符串列表、aliases对象（昵称到名单内姓名）。文件完整替代默认名单及昵称表，需同时保留仍然有效的成员和对应关系。aliases的目标必须在names内，不能将一个成员姓名映射成另一成员。此文件属于本机配置，不随Git或便携包迁移，新电脑需要单独核对。

后台AI的输出合同、提示词、服务器核验、导入及人工修改都执行名单限制；不能仅依赖提示词。只读Codex可读取office_staff、owner、owner_basis和communication_participants，分析时区分办公室跟进人、原消息发言人及实际执行人，不按业务员催问次数认定内部负责人。
