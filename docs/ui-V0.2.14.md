# 生产管理界面 V0.2.14

模式：Operate。本轮沿用现有蓝色、系统中文字体、深浅色随系统的界面风格，优化布局与阅读密度。

主要任务：先看优先事项，再筛选跟进清单、查看依据、登记实际处理。生产单、工序、交付及售后分别留档。

视觉规则：背景、内容、导航三个中性色层次；蓝色表示当前选择与主要操作，红色表示优先/返工，绿色表示已完成。字号24/18/16/14/12px；4px间距基准，主要分组24px、组内8至16px。操作按钮至少42px，手机44px，输入框保持原生。

电脑使用196px侧栏，主内容两列；1180px收窄导航，780px以下转横向可滚动导航、单列清单和原生详情弹层。统计采用分隔条，原消息依据渐进展开，数据和统计口径不变。

检查范围：登录、总览、筛选、详情、生产单/单件/工序、售后、数据覆盖、账号，深浅色与375px手机。验收使用隔离虚构数据，不改正式数据库。

本机上一界面备份：analysis/app_qa_V0.2.14/，包含改版前HTML、CSS及两个JS文件。该目录仅在本机，不进入发布包。
