彩灯生产管理系统 V0.3.0——开始使用

1. 把整个运行包解压到这台电脑的独立文件夹，例如 D:\彩灯管理。
   不要放进旧恐龙看板的安装目录，不要复制旧系统的private或数据库。

2. 双击“启动彩灯看板_V0.3.0.cmd”。
   浏览器会打开 http://127.0.0.1:8770/。
   同事在同一公司内网访问启动窗口显示的内网网址，无需每人安装。

3. 管理员江红账号：jianghong。
   跟单黄钰萌账号：huangyumeng；跟单田秀玲账号：tianxiuling。
   首次随机密码在本安装目录 private\彩灯初始账号.txt。
   首次登录先改自己的密码，再在“账号管理”给同事建立独立账号。
   查看账号只能看和导出；处理账号可以登记、更新项目与出货台账。

4. 第一版先这样用：
   项目进度 → 新建项目 → 填订单/国家/电压/完工日期 → 添加产品。
   按丝架、装灯、裱糊、上色更新实际进度，完成时写明依据。
   出货台账 → 新增出货 → 填资料提供情况、ETD/ETA等 → 导出表格。
   不确定的内容留空，生产单先留存再由人员核对录入。

5. 微信群、阿里企业邮箱、生产单自动识别、固定清关模板，等你到现场拿到材料后再接。
   包内已带通用微信/语音运行组件，组件齐全不等于已绑定或已真实采集。
   “接入与资料”可下载资料收集清单；先要生产单、进度表、群名和人员名单即可。

6. 日常再次双击同一个彩灯启动入口即可。
   数据在 private\lantern.sqlite3，原始上传文件在 private\lantern_uploads。
   不要删除private目录；账号、密码和已录入资料都在本机保存。
   备份时由维护人员使用SQLite备份或停止本项目服务后复制private。

需要Codex协助部署时：先让他阅读 INSTALL_FOR_CODEX.md 和 docs\lantern-installation.md。
先核对运行包SHA-256，再启动、改密、添加一个真实项目，并用同事设备验证内网访问。
初始密码只在本机查看，不放进微信群、代码仓库或对外文档。
