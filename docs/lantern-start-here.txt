彩灯看板 V0.3.26——直接部署

1. 将完整运行包解压到独立文件夹，例如 D:\彩灯管理。
2. 双击“启动彩灯看板_V0.3.26.cmd”。本机网址：http://127.0.0.1:8770/。
3. 首次随机密码在本安装目录 private\彩灯初始账号.txt。
   江红管理员：jianghong；黄钰萌跟单：huangyumeng；田秀玲跟单：tianxiuling。
   每人首次登录后改自己的密码。同事用公司内网网址登录即可，不必每人安装。

界面沿用恐龙看板：总览、出货台账、制作报关资料、设置。
集中整理读取部署时明确配置的彩灯群/邮箱，保留人工结果；个人只读令牌仅管理员用于Codex读取。

报关资料：导航栏“制作报关资料” → 上传PI和装箱单（也可手填）→ 核对 → 选择公司 → 生成Excel。
装箱表优先取唯一“总计/合计/TOTAL”行，提取件数、毛重、净重和体积，不重复加明细。
将另行本机交付的模板资料包解压到同一安装目录，得到 private\lantern_templates 下三个公司模板。
GitHub运行包不包含客户PI、公司原模板、业务数据或密码。

让现场Codex先读 INSTALL_FOR_CODEX.md 和 docs\lantern-codex-deploy.md。
微信群、阿里企业邮箱、定时任务在现场按实际需要确认，不在日常看板显示实施清单。
没配置消息来源时，仍可手工登记项目和出货、提取PI与装箱数据、制作报关资料。
不要删除private，不要复制旧恐龙系统的账号或数据库；由维护人员正确备份。

邮箱配置：部署电脑以江红管理员登录 → 设置 → 阿里企业邮箱，填写邮箱和三方客户端安全密码，测试连接后保存，点击“拉取邮件并整理”。默认读取INBOX最近7天全部发件人，可展开收取范围限定发件人。密码不回显或交给模型，附件自动提取并进入总览待核对资料，确认后才建项目或带入报关。邮箱需开通IMAP和三方客户端访问，部署电脑Codex需已登录。钉钉接入暂缓。

员工设置仅显示修改本人密码；邮箱、人员管理及个人只读令牌仅江红管理员使用，接口同样按角色限制。

文件保存与升级：
安装到哪个目录，业务资料就保存在该目录的private文件夹。可首次部署到D:\彩灯管理系统等固定位置。
private/lantern.sqlite3为业务数据库；lantern_uploads为上传原件；lantern_templates为公司模板；lantern_documents为生成报关文件；lantern_jobs为邮件/微信采集与分析记录。
100MB限制为单个手动上传文件大小，不是总存储量。总存储量由磁盘决定。
首次安装解压到独立目录；升级须先备份整个private，保留原private及账号/授权文件，不能以空private替代，不能只搬数据库丢掉附件。

邮箱附件核对：总览 → 邮箱附件待核对 → 下载原件/查看提取原文 → 选择类型并修改字段 → 勾选已核对。生产单确认会新建项目，四工序均未开始；PI/装箱单确认后点击带入报关资料，最后仍核对本页再生成。重复拉取不会覆盖人工核对结果。
格式：XLS/XLSX、DOCX、CSV/TXT、文字PDF、PNG/JPG/BMP/TIFF及扫描PDF。扫描件使用Windows内置OCR，现场Codex应验证本机OCR语言组件和真实样本；缺少组件时保留原件等待处理，不能称已识别。旧DOC请转DOCX/PDF，压缩包/附加邮件不自动打开。PDF最多100页，超过文字上限会明确说明覆盖不完整。
新增待核对资料在private/lantern_inbox_files，记录及确认人保存于lantern.sqlite3；升级仍保留整个private。邮箱安全密码不进入模型输入，提取的附件文字可由Codex分析。
