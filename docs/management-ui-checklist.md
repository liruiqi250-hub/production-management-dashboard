# 管理看板功能完整性检查 V1.0.0

维护人员开发管理入口时，应一次检查下列配套项，避免让用户逐项补提。按实际需求实施，不据此擅自改变业务判断或扩大权限。

- **一眼看清**：姓名、待处理总数、生产/售后分项及待分派；零事项人员也保留。
- **统计口径**：区分全部未结和超过三天的优先事项；已完成不计、售后待并案不重复计；说明日期筛选是否影响数字。
- **数字对得上**：姓名按钮的数量、个人清单和全部数量来自同一份数据；保存处理结果或刷新后同步更新。
- **点得进去**：点击姓名查看清单，清单事项直达准确详情；与日期、状态或群筛选冲突时仍能找到目标。
- **内容够简洁**：摘要、办公室跟进人、确认状态、下一步和优先标记；原始依据放在详情。
- **异常有交代**：待分派、零匹配、数据更新、权限不足、会话退出都有明确状态；不残留上一人的旧列表。
- **选择不白做**：刷新保留选择；退出清空私有内容及选择；展开全部只展开当前选中人员的清单。
- **多端能用**：电脑及手机实际截图检查，中文、长姓名、换行、点击区域及键盘焦点均需可用。
- **发布可回退**：递增版本、保留旧版，保护账号与人工结果，按项目规则同步私有GitHub并核验完整运行包。

V0.3.11的人员总览覆盖上述人员数量及清单入口。数据只代表已登记范围；负责人推定仍需保留依据，不能仅因发过消息就分派。
