# V0.3.31 本机验收

本次增加生产单搜索、生成文件七天未使用清理、浏览器/云打印入口，以及本机固定打印队列。沿用已有生产进度、账号及人工记录口径。

## 搜索与界面

- 真实生产单的隔离副本中，`Chloe`、`俄罗斯 Chloe`均只命中俄罗斯生产单，显示1/4张单、40条产品记录；刷新保留搜索，零匹配提供清空提示。
- 支持单号、标题、业务员、客户、跟单员、原文件名/来源及产品关键词，多词取交集；订单下拉与搜索同时生效，命中保留完整订单。
- 1280×720电脑截图中，下拉与搜索输入顶边均为431.265625px，无横向溢出；390×720手机实际页面的scrollWidth与innerWidth均为390，搜索、清空和匹配订单可用。
- 浏览器打印入口为真实同源链接，实际从预览设置点击后进入对应打印页，全部图片就绪后才启用打印按钮；没有依赖内置浏览器拦截的新窗口。
- Impeccable对index、生产进度JS、资料JS、主样式及打印页JS/CSS检测返回`[]`；静态检测之外已做截图目视检查。
