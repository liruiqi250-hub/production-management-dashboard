# 生成资料清理与打印设计 V0.3.31

用户已选择生成文件7天后清理，并要求页面打印、云打印及同事提交到本机打印。

生产进度在“查看生产单”旁增加“搜索生产单”。只筛选生产订单，命中单号、标题、业务员、客户、跟单员、原文件名/来源与产品关键词；多个空格分隔的词取交集，与下拉选择共同生效。英文不区分大小写，兼容全角输入。结果保留整单及其全部产品，明确显示匹配订单和产品记录数，零匹配给出清空提示。刷新保留、退出清空，其他入口直达单件时自动解除遮挡目标的筛选。

生成的Excel、PDF和预览PNG按7天未使用清理，读取预览、下载及打印会更新使用时间，列表刷新不会延长。原生产单、模板、业务台账与生成批次历史保留；清理后可按当前原单重新生成。生成中、正在读取及待打印批次不清理。未知文件、链接、路径异常或摘要已变动的文件保留并记录原因。清理在服务启动及每6小时后台维护中执行，服务未运行时顺延到启动。

预览旁增加两个入口：

- 打印 / 云打印：打开本次PDF对应的同源打印页，全部选定页面实际图片载入后，用户打开系统打印对话框，选择自己电脑已配置的打印机或钉钉云打印机。云设备登录、选设备沿用其客户端，不声称已有云端API对接。
- 由本机打印：显示本机固定柯尼卡队列、页码与份数，用户提交后进入持久队列。已登录查看账号可打印，写工序权限不扩展。API令牌不能提交。重复请求按用户和request_id去重，后台串行调用本机LibreOffice UNO，经过Windows驱动提交。

本机队列使用现有 `KONICA MINOLTA bizhub C226 PCL (192.168.10.199) UPD`，实际绑定端口目标为192.168.253.253:9100，已做零载荷TCP连通检查；不修改系统默认打印机或端口。配置保存在private，客户不能传入任意打印机、路径或命令。页码严格校验，1–5份，总纸面上限250。提交前显示纸面数。

已提交只代表交给Windows打印系统；不自动宣称已出纸。重启遇到可能已提交的任务标为待确认，不自动重打。打印任务中的PDF副本只在队列使用期间保留，终态清理副本并保留记录。开发验证不向实体或云设备发出任务。

沿用现有暗色、中文、44px按钮和预览层级，新增状态及表单不另开管理模块。版本递增，保留V0.3.30源码/数据库回退，本机验证后再询问GitHub发布。
