# V0.2.3 初始密码与本人改密

用户已明确要求将现有账号统一为指定初始密码，然后进入系统修改本人密码。本次沿用既有角色和内网范围，增加首次改密流程，并迭代版本为0.2.3。

执行期间用户进一步提供厂长中文名“曾悦”；授权管理及登录后的显示姓名同步更新，登录账号zengyue保持。

现有全部账号一次性重置，分别生成盐并保存密码哈希。重置会删除旧登录会话、撤销旧令牌，保留启用状态与角色，标记必须改密。统一密码只用于本次授权操作，不写入源码、测试或版本说明，不在启动时反复重置。

待改密账号登录后显示姓名及改密表单；输入初始密码、新密码、重复新密码。新密码继续采用10至120字符，不能与原密码相同。完成后清除标记并重新登录。此期间后端只允许读取本人登录信息、修改本人密码、退出；不能读取台账或报表、修改事项、管理账号或创建令牌。新增账号及以后管理重置密码同样需要本人先改密。

数据库新增布尔字段must_change_password，旧库迁移默认不改变现有密码；只有本次明确重置才将现有用户标为待改密。验证在临时数据库进行，真实账号验证只测试初始登录和数据拦截，不替用户设置新密码。
