# 独立彩灯系统实施计划

目标：在现有看板代码基础上建立独立账号、数据库和入口的彩灯系统，交付项目进度、出货台账和资料收集清单。

架构：复用Python标准库HTTP/SQLite及认证基础；彩灯业务存储、路由、网页和启动器独立。原生产服务和运行数据保持现状。

- [ ] 后端：app/lantern_store.py 管理项目、产品节点、出货台账、审计和乐观锁；app/lantern_server.py 只提供彩灯与账户白名单接口，使用独立cookie和数据库。
- [ ] 前端：web/lantern 中实现登录改密、项目管理、四节点进度、出货台账、账号管理、接入状态及清单下载；所有未知字段留空。
- [ ] 启动与资料：独立启动脚本核查本项目PID和health；资料清单按生产、出货、模板分批收集；独立本机安装不复制业务数据。
- [ ] 验证：tests/test_lantern.py 使用临时库验证权限、完成依据、版本冲突与导出；隔离测试服务进行浏览器真实操作和手机布局检查。
- [ ] 发布：统一版本0.3.0，保留既有更新，清洁发布main和v0.3.0；完整便携ZIP、SHA、准确对应源码附件，核对远端私有性、版本和资产。
