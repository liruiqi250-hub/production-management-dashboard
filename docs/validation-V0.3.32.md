- 网页 OAuth 回调成功后，由服务端验证短期、一次性且绑定对应会话或待绑定状态的返回凭据。已绑定账号继续原认证加载，首次绑定保留本人账号密码及明确勾选确认，不再重复请求原生免登清除它。
