# 彩灯系统独立安装 V0.3.0

彩灯系统与恐龙生产看板使用独立启动入口、数据库、账号和浏览器会话。可以安装在另一台Windows电脑，也可以在同一电脑不同目录运行。

1. 接收者Codex先阅读根目录 `INSTALL_FOR_CODEX.md`，下载同一版本完整Windows x64运行包，核对SHA-256后解压至独立目录，例如 `D:\彩灯管理`。不要从原看板复制 `private`、`acquisition`、数据库或微信绑定。
2. 双击 `启动彩灯看板_V0.3.0.cmd`。本机默认地址 `http://127.0.0.1:8770/`；实际内网地址由启动器显示。原看板仍使用8769，彩灯启动器不会停止或重启原服务。
3. 首次建立江红管理员（jianghong）、黄钰萌跟单（huangyumeng）、田秀玲跟单（tianxiuling），各自随机初始密码保存在彩灯安装目录的 `private/彩灯初始账号.txt`。每人修改本人密码后才能进入系统。管理员可以新增处理或只读账号。
4. 在“项目进度”新建项目，填写已确认的订单、国家、电压、完工日期、业务员、跟单员和产品；生产单可以上传留存，首版由人员核对后录入字段。各产品按四工序更新，已完成须填写实际依据。
5. “出货台账”登记需求中的全部字段，明确资料状态和ETD/ETA；项目关联由人员选择，不自动推断。多人修改时系统检查记录版本，冲突保留表单并要求重新核对。
6. “接入与资料”下载资料清单。阿里企业邮箱、指定彩灯微信群、生产单自动识别和固定模板套打尚待真实材料与独立配置，当前页面不会宣称已自动接通。

数据存放在彩灯安装目录的 `private/lantern.sqlite3` 及 `private/lantern_uploads`。账号与修改审计均属于本机业务数据，备份时使用SQLite备份或停止已核对的本项目进程后复制，不能上传GitHub。保留原组件来源、许可及SHA-256文件。

同事通过公司内网网址登录即可使用，不需要重复部署采集。其他设备连通需现场实测。公网访问和邮件发送不属于本次默认配置。
