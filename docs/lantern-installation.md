# 彩灯看板 V0.3.4 独立安装

快速部署见 `docs/lantern-start-here.txt`，现场Codex步骤见 `docs/lantern-codex-deploy.md`。默认8770端口，双击 `启动彩灯看板_V0.3.4.cmd`。

样式、深色模式、认证权限、个人令牌、后台Codex工具直接复用恐龙看板。彩灯账号、数据库和采集范围独立。江红为销售支持部主管及管理员，同时参与跟单；黄钰萌、田秀玲为跟单，首次随机密码只在新电脑本机生成。

出货台账内“制作报关资料”：上传PI和装箱表，提取收货人、地址、条款、金额及装箱四项总计，支持手填。人员核对并勾选后，填写所选公司原模板生成待核对Excel。旧客户、目的国和旧仿真恐龙产品事实清除，未知申报信息留空，不增加签章或自动发给外部联系人。

模板本机资料包另行解压到安装目录，客户原件、上传件、授权和数据库全部留private，不上传GitHub。内网访问、真实采集、邮箱授权和每日任务在现场分别验收。

员工设置仅显示修改本人密码；邮箱、人员管理及个人只读令牌仅江红管理员使用，接口同样按角色限制。

邮箱附件核对：总览 → 邮箱附件待核对 → 下载原件/查看提取原文 → 选择类型并修改字段 → 勾选已核对。生产单确认会新建项目，四工序均未开始；PI/装箱单确认后点击带入报关资料，最后仍核对本页再生成。重复拉取不会覆盖人工核对结果。
格式：XLS/XLSX、DOCX、CSV/TXT、文字PDF、PNG/JPG/BMP/TIFF及扫描PDF。扫描件使用Windows内置OCR，现场Codex应验证本机OCR语言组件和真实样本；缺少组件时保留原件等待处理，不能称已识别。旧DOC请转DOCX/PDF，压缩包/附加邮件不自动打开。PDF最多100页，超过文字上限会明确说明覆盖不完整。
新增待核对资料在private/lantern_inbox_files，记录及确认人保存于lantern.sqlite3；升级仍保留整个private。邮箱安全密码不进入模型输入，提取的附件文字可由Codex分析。
