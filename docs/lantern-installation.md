# 彩灯看板 V0.3.1 独立安装

快速部署见 `docs/lantern-start-here.txt`，现场Codex步骤见 `docs/lantern-codex-deploy.md`。默认8770端口，双击 `启动彩灯看板_V0.3.1.cmd`。

样式、深色模式、认证权限、个人令牌、后台Codex工具直接复用恐龙看板。彩灯账号、数据库和采集范围独立。管理员江红，跟单黄钰萌、田秀玲，首次随机密码只在新电脑本机生成。

出货台账内“制作报关资料”：上传PI和装箱表，提取收货人、地址、条款、金额及装箱四项总计，支持手填。人员核对并勾选后，填写所选公司原模板生成待核对Excel。旧客户、目的国和旧仿真恐龙产品事实清除，未知申报信息留空，不增加签章或自动发给外部联系人。

模板本机资料包另行解压到安装目录，客户原件、上传件、授权和数据库全部留private，不上传GitHub。内网访问、真实采集、邮箱授权和每日任务在现场分别验收。
