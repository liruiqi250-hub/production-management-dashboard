# CMD 入口用途（V0.3.35）

根目录只保留四个常用入口：

| 入口 | 用途 |
|---|---|
| 启动生产看板.cmd | 启动当前生产看板；支持 NoBrowser、PythonPath、LanAddress、Port 参数 |
| 检查运行环境.cmd | 检查 Python、SSL、SQLite、PDF 浏览器和内网条件 |
| 检查完整安装.cmd | 检查完整微信/语音运行包；不会替代真实账号绑定验收 |
| 配置微信采集.cmd | 在部署电脑按授权配置微信采集绑定 |

current 存放当前版本命名入口；legacy/production 存放 50 个旧生产启动兼容入口；legacy/environment 存放 44 个旧环境检查兼容入口。

这些旧版本文件名指向同一安装目录的当前脚本，保留主要用于查找和兼容旧习惯。文件搬到子目录后已修正脚本相对路径，可以从任意工作目录调用并透传参数。原来指向根目录的外部快捷方式需要更新目标，日常建议改用根目录固定名称入口。

旧 CMD 不包含旧程序，不具备回退软件的作用。真实回退应使用相应历史 Release 与本机备份，保留账号和业务资料。彩灯项目继续使用独立仓库与启动入口；本生产发布不包含彩灯兼容文件。
