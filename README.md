## Codex只读接口

每位用户登录“账号与Codex”，生成自己的只读令牌（7/30/90天可选，明文仅显示一次），不要共享他人令牌。数据库只保存令牌哈希，可随时吊销。

请求头：`Authorization: Bearer <个人令牌>`。

- `GET /api/v1/overview`：覆盖、团队与事项。
- `GET /api/v1/items`：事项和来源证据。
- `GET /api/v1/production`：生产单、逐件产品、工序状态及人工修改记录。
- `GET /api/v1/reports?kind=daily&end=2026-10-12&format=json`：日报结构化数据。
- `GET /api/v1/reports?kind=weekly&end=2026-10-12&format=json`：周报结构化数据。

只读令牌不能改正式事项、创建账号或生成其它令牌。页面提供可复制的中文总结提示词，要求区分事实、推断与建议，并保留来源。当前角色均查看同一全厂台账；如以后需要按订单或小组隔离，需要增加对应数据权限，不能由账号名称自动实现。

## Windows登录自启与静默检查

V0.3.17：在服务器电脑运行 `powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File scripts/install_startup_V0.2.0.ps1` 安装或更新当前用户任务；非默认端口可用 `-Port 8770`。仅同目录任务可覆盖，新目录与旧目录冲突须维护人员明确迁移。使用随包pythonw.exe，当前Windows用户登录后启动，每5分钟检查；健康时只发一次本机HTTP请求，不启动PowerShell、不打开浏览器、不重复启动服务。不可达时无控制台调用带进程身份校验的启动器；版本/端口冲突不自动停止未知进程。异常只覆盖本机 `private/startup_last_error.log`，不会无限堆积日志。

网页服务无需打开Codex。电脑须保持开机、登录并连接内网；关机、睡眠无法访问。微信采集、语音转写与AI整理需要各自已授权运行环境，不能用网页健康代替真实整理验收。内网地址以启动器实际显示为准，路由器分配地址可能改变。

V0.3.17支持可选钉钉登录。企业应用管理员按 `docs/dingtalk-login.md` 完成本机私有配置与真实扫码验收后，电脑可使用钉钉扫码，手机可使用钉钉授权。首次用本人现有看板账号密码勾选确认绑定；之后按稳定身份匹配，不按昵称建号或赋权。钉钉工作台真正静默免登不属于本版验收，仍需用户完成钉钉授权。应用密钥仅保留本机，禁止写入源码、聊天或运行包。当前登录会话仍为12小时。
