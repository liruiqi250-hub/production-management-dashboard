## 使用

待本人改密期间只能查看本人登录信息、修改本人密码或退出，不能读取生产数据和报表，也不能生成或使用Codex令牌。原会话和原令牌已失效；本人改密登录后可重新生成个人只读令牌。新增或管理重置的账号同样需要本人先改密。服务重启不会再次重置密码。

跟进清单采用一句话摘要，正文最多显示两行；点击事项可查看完整说明、原文及下一步。摘要独立保存在metadata，原始内容不改；事项进展或人工更新后过时摘要自动失效，避免完成后仍显示旧待办。

顶部“导出日报”对应所选结束日期当天；“导出周报”对应该日及前6天。点击后在当前页面生成并直接触发文件下载，默认PDF，也可选择HTML网页打印稿和CSV台账。生成中按钮显示进度且防止重复点击；失败或登录过期会提示，页面不跳转。来源截止、缺失媒体、审核状态和证据定位均保留。

## Codex只读接口

每位用户登录“账号与Codex”，生成自己的只读令牌（7/30/90天可选，明文仅显示一次），不要共享他人令牌。数据库只保存令牌哈希，可随时吊销。

请求头：`Authorization: Bearer <个人令牌>`。

- `GET /api/v1/overview`：覆盖、团队与事项。
- `GET /api/v1/items`：事项和来源证据。
- `GET /api/v1/reports?kind=daily&end=2026-10-12&format=json`：日报结构化数据。
- `GET /api/v1/reports?kind=weekly&end=2026-10-12&format=json`：周报结构化数据。

只读令牌不能改正式事项、创建账号或生成其它令牌。页面提供可复制的中文总结提示词，要求区分事实、推断与建议，并保留来源。当前角色均查看同一全厂台账；如以后需要按订单或小组隔离，需要增加对应数据权限，不能由账号名称自动实现。

## 数据与维护

- `private/production_V0.2.0.sqlite3`：账号、令牌哈希、事项、人工更新和审计。备份时应同时保留SQLite相关WAL文件或在关闭服务后复制。
- `acquisition/`：原聊天、媒体与每轮采集manifest；不被网页直接提供，也不提交Git。
- `private/daily_snapshots/`及其它 `daily_snapshot*`：经复核的导入快照。
- `outputs/V0.2.0/`：可导出的报表。
- `scripts/import_snapshot_V0.2.0.py`：幂等合并，保留人工修改和未结历史。

首版是独立Python/SQLite内网服务，未集成NocoBase。环境选型证据见 `docs/环境选型核验_V0.2.0.md`。没有对外开放域名、没有变更Windows防火墙；其它设备实际连通仍需同一公司内网实测。

### 新电脑使用便携包

1. 在[版本下载页](https://github.com/liruiqi250-hub/production-management-dashboard/releases)下载对应版本Windows x64 ZIP，解压到本机可写目录（Windows 10/11，64位）。
2. 双击 `检查运行环境_V0.2.7.cmd` 检查看板与PDF组件；双击 `启动生产看板_V0.2.7.cmd` 启动。随包提供Python和PDF渲染组件，主体无需另装Python、Node或pip包。
3. 新副本首次启动为空台账，管理与厂长初始账号随机生成在该副本的 `private/初始账号_V0.2.0.txt`；登录后必须本人改密。现有办公室服务的密码和数据不会因代码更新而重置。
4. 同一内网其它设备使用启动器显示的地址。由接收者的Codex安装时，先阅读根目录 `INSTALL_FOR_CODEX.md` 与 `docs/Codex安装验收.md`。只查看或用Codex读取数据的同事直接连接办公室看板，不必重复部署采集。
5. V0.2.7完整包文件名含`full`，额外带独立Python 3.12、微信采集依赖、SILK解码、FFmpeg和SenseVoice离线模型；运行`检查完整安装.cmd`。组件无需另装，本机微信登录与授权绑定仍需按 `dependencies/微信采集依赖.md` 配置。已有Codex每日整理任务需要在实际接替采集的电脑单独设置。

随包Python、PDF组件保留原始LICENSE及第三方说明，版本、官方来源和SHA256见 `dependencies/windows-x64.lock.json`。ZIP内 `SHA256SUMS.json` 校验每个文件，下载页另提供ZIP本身校验值。

已提交代码后运行 `python scripts/build_portable.py --with-wechat` 构建当前完整包；省略此参数仅构建核心看板包。公开依赖首次下载后缓存于本机runtime；可用 `--offline` 只使用已校验缓存。完整包内组件、来源和许可由微信及媒体依赖锁记录；配套第三方准确源码及构建材料在同一Release下载。每次发布将完整ZIP、校验文件和许可要求的源码资产上传对应标签Release，操作约定见AGENTS.md。

看板服务使用Python标准库，可用Python 3.12及以上版本启动：

```powershell
python -m app.server --host 0.0.0.0 --port 8769 --lan-ip 192.168.10.237
```

`--lan-ip`应替换为运行电脑的公司内网IPv4地址。启动器优先使用随包Python，再检测系统完整Python和原电脑兼容路径；支持内网以太网或Wi-Fi，离线时可本机使用。也可传 `-PythonPath`、`-LanAddress` 和 `-Port` 显式指定运行条件。

运行隔离验证：`python -m unittest discover -s tests -v`。仓库副本没有授权本机的采集材料时，会跳过NormalizeTests的真实证据回归，其余使用虚构材料。PDF导出优先随包无头浏览器；源码方式也可使用已安装的Microsoft Edge或Chrome。微信采集使用完整包内的导出器和运行环境，但必须配置本机已授权账号绑定，仓库代码不会自行获得微信访问权限。
